# ChatGPT

In ChatGPT developer mode, create a custom connector/app using this remote MCP server:

```text
https://staging.attenza.io/mcp
```

Choose OAuth when prompted. ChatGPT should discover Attenza's protected-resource and authorization-server metadata, then open Attenza sign-in and consent for the current user.

Public directory publication is a separate review process; this repository is the auditable source package and testing documentation.
