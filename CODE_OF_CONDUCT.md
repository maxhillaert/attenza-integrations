# Code of conduct

We want participation in this project to be welcoming, constructive, and safe.

Be respectful, assume good intent while addressing concrete behavior, give actionable technical feedback, and avoid harassment or discrimination. Maintainers may edit or remove abusive contributions and restrict participation when needed.

Report conduct concerns privately to the repository maintainers. Report security issues through the process in [SECURITY.md](SECURITY.md), not through public issues.
