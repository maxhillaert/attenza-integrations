# Security policy

## Reporting a vulnerability

Please use the repository's **Security** tab to report vulnerabilities privately through GitHub Security Advisories. Do not open a public issue.

Include the affected package and version, impact, reproduction steps using synthetic data, and any suggested mitigation. Never include live OAuth tokens, authorization codes, private capability URLs, personal task contents, or customer data.

## Supported versions

Security fixes are applied to the latest release. This repository contains public client configuration and behavior guidance; the Attenza service implementation lives separately.
