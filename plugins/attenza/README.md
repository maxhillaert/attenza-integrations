# Attenza for Codex

This package gives Codex the Attenza intervention skill and connects it to the public OAuth-protected MCP endpoint. Each user signs in to Attenza and grants their own revocable access; the package contains no shared credential.

Install it from this repository's marketplace, then ask Codex to send a decision to Attenza. The agent will create the intervention and wait for the recorded answer before resuming gated work.
